# EventSphere Final Requirements

## Project objective

Build a MERN web application that manages expos and trade shows for organizers, exhibitors, and attendees.

## Required technology

- [ ] React.js frontend
- [ ] Node.js backend
- [ ] Express.js API
- [ ] MongoDB database
- [ ] JWT authentication
- [ ] Bcrypt password hashing
- [ ] Socket.IO or another method for required live updates

## Required user roles

- [ ] Admin/Organizer
- [ ] Exhibitor
- [ ] Attendee

## Authentication requirements

- [ ] Registration
- [ ] Login
- [ ] Logout
- [ ] Password hashing
- [ ] Forgot password
- [ ] Reset password
- [ ] JWT-protected routes
- [ ] Role-based authorization

## Organizer requirements

- [ ] Create, edit, and delete expos
- [ ] Manage title, date, location, theme, description, and status
- [ ] View exhibitor applications
- [ ] Approve or reject applications
- [ ] Create and manage booths
- [ ] Assign booths without double booking
- [ ] Create, edit, and delete sessions
- [ ] Manage speakers, topics, time slots, and locations
- [ ] View attendee registrations
- [ ] View basic attendee, booth, and session analytics
- [ ] Manage feedback and support requests

## Exhibitor requirements

- [ ] Create and update company profile
- [ ] Add logo, description, products, services, and contact details
- [ ] Upload required documents
- [ ] Apply for expos
- [ ] View application status
- [ ] View available booths
- [ ] Request or select a booth
- [ ] View assigned booth
- [ ] Add booth information and staff details
- [ ] Contact the organizer

## Attendee requirements

- [ ] Browse expos
- [ ] View expo details
- [ ] Register for expos
- [ ] View exhibitor list
- [ ] Search and filter exhibitors
- [ ] View exhibitor profile and booth location
- [ ] View floor-plan information
- [ ] View schedules and sessions
- [ ] Register for sessions
- [ ] Bookmark sessions
- [ ] Receive important notifications
- [ ] Submit feedback

## General requirements

- [ ] Responsive design
- [ ] Form validation
- [ ] Useful error messages
- [ ] Loading and empty states
- [ ] Secure handling of sensitive data
- [ ] Basic notifications
- [ ] Required real-time updates
- [ ] Basic analytics
- [ ] Logging and error handling
- [ ] Database backup
- [ ] User and developer documentation
- [ ] Complete working demonstration video

## Out of scope

- [ ] Online payments
- [ ] Mobile application
- [ ] AI features
- [ ] Social media integration
- [ ] QR ticket scanning
- [ ] Separate speaker or sponsor portals
- [ ] Multi-language support
